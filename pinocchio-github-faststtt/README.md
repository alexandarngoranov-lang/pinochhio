# Pinocchio Leuven

Static production build, ready for GitHub Pages.

## Publish

1. Put every file and folder from this package at the repository root.
2. Commit and push to the `main` branch.
3. In **Settings → Pages**, select **GitHub Actions** as the source.
4. Open the Pages URL after the `Deploy Pinocchio` action is green.

No build step, Node.js installation, or `dist` folder selection is required.
